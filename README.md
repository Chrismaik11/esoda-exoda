# Έσοδα–Έξοδα

Εφαρμογή εσόδων-εξόδων για επιχειρήσεις — πολλοί χρήστες, ρόλοι, cloud συγχρονισμός.

**Live:** https://chrismaik11.github.io/esoda-exoda/

## Τι κάνει
- **Σύνοψη** — ισοζύγιο περιόδου, υπόλοιπα τραπεζών/καρτών, πρόσφατες κινήσεις, εργασίες
- **Ταμείο** — ημερήσιος τζίρος & κουβέρ, με φωνητική καταχώρηση
- **Κινήσεις** — έσοδα/έξοδα με κατηγορίες, τρόπο πληρωμής, τράπεζα, σημειώσεις, αναζήτηση, επεξεργασία
- **Πληρωμές** — προγραμματισμένες πληρωμές με ομαδοποίηση και μηνιαία επανάληψη
- **Αναφορά** — P&L, ανάλυση ανά κατηγορία, σύγκριση περιόδων, προμηθευτές
- **Ρυθμίσεις** — τράπεζες, κατηγορίες, πάγια & μισθοδοσία, Google Calendar, κλειδί Gemini

Επιπλέον: φωνητική καταχώρηση στα ελληνικά, σάρωση αποδείξεων με AI, ειδοποιήσεις μέσω
Google Calendar, εγκατάσταση στην αρχική οθόνη (PWA), λειτουργία εκτός σύνδεσης.

## Τεχνικά
Στατική εφαρμογή — καθαρή JavaScript σε ES modules, **χωρίς build step**.
Δεδομένα: Firebase (project `esoda-exoda`) — Firestore + Authentication.
Φιλοξενία: GitHub Pages.

| Αρχείο | Περιεχόμενο |
|---|---|
| `index.html` | HTML — οθόνες και φόρμες |
| `styles.css` | Εμφάνιση |
| `config.js` | Ρυθμίσεις Firebase |
| `util.js` | Κοινές βοηθητικές συναρτήσεις |
| `engine.js` | Μαθηματικά αναφοράς (P&L, κατανομή πάγιων) |
| `voice.js` | Φωνητική καταχώρηση + σάρωση αποδείξεων |
| `calendar.js` | Συγχρονισμός με Google Calendar |
| `app.js` | Κύρια λογική |
| `sw.js`, `manifest.webmanifest` | PWA (εικονίδια ενσωματωμένα) |

## Ενημέρωση
Ανέβασε τα αλλαγμένα αρχεία στο repo — το GitHub Pages ενημερώνεται μόνο του σε ~1 λεπτό.
